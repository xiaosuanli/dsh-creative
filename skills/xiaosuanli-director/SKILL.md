# DSH 导演台

在 DeepSeek Harness 中使用本插件。工具尚未安装时，按[安装指引](references/install.md)安装并重启对应 profile；已有 xiaosuanli_connection 时直接连接。

1. 调用 `xiaosuanli_connection`。未连接时使用插件“小算狸”账户入口，生成链接并在系统默认浏览器授权；一次性码填插件授权入口，不发送给模型。
2. 点击右下角“小算狸”悬浮按钮按需展开面板，或通过聊天初始化。`xiaosuanli_projects` 呈现工程，`xiaosuanli_chapters` 呈现所选工程的章节。用户选定后 `xiaosuanli_open_chapter`；面板也可为选定章节新建聊天。工程或章节列表为空时，主动转入下方首次使用流程。
3. 当前对话固定一个章节。不同对话允许同章，以最后真实用户消息接管；旧对话发新消息可接管，打开/查询/后台续跑不抢权。身份由宿主钩子注入，不能自行伪造。
4. 用户要求新建时用 `xiaosuanli_create_project` 或 `xiaosuanli_create_chapter`；已绑定聊天需要新建其它范围时另开聊天。先读回成功回执再继续。
5. 读取[公共导演指引](references/director-workflow.md)。公共说明中的操作名统一加 `xiaosuanli_`；精确参数以当前工具 Schema 为准。
6. 返回 `editorUrl`，提醒用户可在同环境导演台网页图形化修改。网页改动后先刷新再写，保留用户修改。

## 引用本章素材与节点

聊天绑定章节后，在 DSH 输入框输入 `@`，可按名称搜索本章人物、物品、场景、文档、视频节点和幕节点，与 DSH 原有文件/会话候选并存。选择只插入引用，不修改素材或开始生成。

收到“小算狸章节引用”或 `xiaosuanli:` 引用时，以其中的工程、章节、kind 和 id 定位对象；名称只是显示标签。先通过当前聊天的 `xiaosuanli_connection` 和 `xiaosuanli_project_get` 读取最新内容、核对归属和版本，再按用户要求操作。引用本身不授予权限，不能用另一章节的引用切换当前聊天。对象已删除或归属不符时说明并请用户重新选择。需要观察图片时使用实际工具提供的媒体读取能力，不能仅凭名称声称看过画面。

账号、额度与权限来自服务端；网络错误、未上线工具或缺权限如实说明，不声称已经生成或保存。内部实现和私密数据不向用户输出。

## 首次使用：没有工程或章节

1. 引导用户先在悬浮面板连接账号、完成网页授权，并将一次性码填回插件。没有工程时，选择授权页提供的账号级工程选择/创建权限；若当前网页只能选择已有工程，提供本环境导演台主页，让用户先在网页创建，再回来授权。
2. 在 DSH 新会话中，用户可直接说：“使用小算狸导演 Skill，帮我创建一个叫《我的第一部短片》的工程。”已有明确名称就直接执行；缺少名称时只询问名称。调用 `xiaosuanli_create_project`，成功回执中的工程包含空白第一章，向用户说明并邀请打开；用户已要求创建并开始创作时，直接打开返回的第一章。
3. 用户已有工程但没有章节，或想新增章节时，先列出并确认目标工程，再读取章节目录提供的剧本与版本，调用 `xiaosuanli_create_chapter`。当前对话已绑定章节时，引导在 DSH 新会话执行创建，保留原对话。
4. 打开章节成功后再接收故事、画风、时长等创作要求，按公共导演指引推进。也可提醒用户点击面板刷新，选择刚创建的工程和章节，再新建章节聊天。

创建空工程/空章节不提交图片或视频生成。权限不足或创建接口不可用时说明具体原因，提供工具返回的同环境导演台链接；不让用户反复刷新空列表，不把空列表当作出错或创建成功。
