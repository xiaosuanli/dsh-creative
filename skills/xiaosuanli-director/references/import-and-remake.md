# 小说解析与视频复刻

## 小说、文章

单章正文不超过 20,000 字时，使用 `text_import`，读回分镜与素材卡，再按用户选定的终点继续。`import_estimate` 可预估，不代表已经解析。用户已要求压缩剧情时先写完整改编稿；没有改编要求时不要自行缩写。

较长小说的产品入口是 `novel_import`，可识别章节并在需要时等待用户选章；`import_select_chapters` 只提交用户明确选定的目录。它可能包含素材图消费，不当作免费的目录读取。当前“一对话一章节”渠道不能跨章调用整本导入时，引导用户在导演台网页导入、选章后再回到对应聊天，不绕过限制。每个制作章节仍遵守单章字数边界。

## 一键复刻视频

“一键”表示用户授权完整制作后，由助手接续完成使用步骤；一次解析成功不等于已有成片。

1. 确认用户选择的源片段、复刻或改编目标，以及画风、人物、语言等明确要求。源视频须为当前用户上传到当前工程的可用素材，时长 15～180 秒。缺少素材时给导演台链接请用户上传，不能编造素材标识，也不把任意网页链接直接当成已上传视频。
2. 使用 `episode_inspect(projectId, assetId)` 读取真实时长和费用，再以 `episode_import` 导入到已打开的空章节。按工具实际参数传递用户选定的语言、分辨率、画风、人物及改编要求；不硬编码人物或题材。
3. 用 `import_get` 查询原任务。读回完整解析成果，核对关键情节、人物关系、对白、镜头顺序与源片段时长；不要把不确定观察写成事实。已有成果先复用，修复失败步骤时保留正确内容。
4. 用户只要求解析时返回分镜与编辑链接。用户要求成片时继续按主 skill 完成必要素材图、视频、结果选择及章节导出。视频导入本身不会自动提交全部视频，不重复创建已有任务。
5. 换语言、画风或人物时保留用户希望保留的故事与因果；未授权改编时忠实处理原片。返回真实成片和工程链接，没有看过实际画面就不声称画面效果已验收。

可随时提示用户打开同环境的导演台网站，图形化调整解析结果或已生成素材。对外不描述内部实现过程、模型配置或基础设施。
